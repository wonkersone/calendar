# 📱 Инструкция по использованию и хостингу

Я подготовил для вас приложение, которое работает как ваш личный генератор календарей-обоев.

### 1. Как это работает (Техническая часть)
Поскольку GitHub Pages — это **статический** хостинг (там нет PHP или Node.js сервера), мы используем магию Canvas.
- URL вида `?auto=true&theme=forest_green` открывает приложение в специальном режиме.
- В этом режиме убираются все кнопки и настройки, остается только чистая картинка.
- Ваше устройство (через Команды iOS или MacroDroid) запрашивает этот URL, а затем "вынимает" картинку из страницы.

### 2. Как захостить на GitHub
1. Создайте **новый репозиторий** на GitHub.
2. Скопируйте туда все файлы из этого проекта.
3. Перейдите в **Settings -> Pages**.
4. В разделе "Build and deployment" выберите ветку `main` и нажмите **Save**.
5. Через пару минут сайт будет доступен по адресу `https://ваш-ник.github.io/имя-репозитория/`.

### 3. Как настроить автоматизацию (iOS Shortcuts)
Для iPhone 15 Pro алгоритм такой:
1. Создайте новую команду в приложении **Команды**.
2. Добавьте действие **"Веб" -> "Получить содержимое URL"**. Вставьте туда вашу ссылку (со всеми параметрами `?auto=true...`).
3. Добавьте действие **"Извлечь изображения из входных данных"**.
4. Добавьте действие **"Установить обои"**.
5. Настройте "Автоматизацию" по расписанию (например, каждый день в 00:01).

### 4. Как расширять функционал
- **Цвета и Темы**: Файл `/src/types.ts`. Просто добавьте новый объект в `THEMES`, и он появится в меню выбора.
- **Отрисовка (Стили)**: Файл `/src/lib/drawUtils.ts`. Там описана логика рисования. Если захотите добавить фазы луны, праздники или картинку на фон — это делается там через `ctx.drawImage`.
- **Размеры**: В `drawUtils.ts` заданы константы `IPHONE_15_PRO_RES`. Приложение автоматически масштабирует всё под экран.

### 5. Как тестировать
Просто открывайте сайт в браузере. Вы сразу увидите превью. Если добавить в конец адреса `?auto=true`, вы увидите, как сайт выглядит для автоматических скриптов.
